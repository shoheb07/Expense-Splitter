# Expense-Splitter
The Expense Splitter is a web-based financial utility application developed using HTML, CSS, and JavaScript. The application helps users divide expenses equally among multiple people.

# Expense Splitter

## Project Overview

The Expense Splitter helps users divide expenses equally among multiple people.

The project is developed using HTML, CSS, and JavaScript.


# Features

- Equal expense splitting
- Instant calculation
- Responsive UI
- Beginner-friendly project

# Technologies Used

- HTML5
- CSS3
- JavaScript


# Run Project

Open index.html in browser.

# Formula

Each Person Share = Total Expense / Number of People
